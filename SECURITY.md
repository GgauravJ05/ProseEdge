# Security Policy

## Supported versions

Only the latest release and `main` receive fixes.

## Reporting a vulnerability

Report privately through
[GitHub Security Advisories](https://github.com/GgauravJ05/ProseEdge/security/advisories/new).
Do not open a public issue. You will get an acknowledgement within 7 days and a
fix or mitigation plan within 30.

## Scope

ProseEdge runs entirely in the browser and sends no user text anywhere. Issues
of particular interest:

- Anything that causes user text to leave the device
- Model or asset loading that could be redirected to attacker-controlled files
- Supply-chain weaknesses in the build or release pipeline
